# ⚖️ Право AI — Юридический AI-ассистент с проверкой источников

Fullstack-приложение для консультаций по законодательству РФ на базе **гибридного RAG (Retrieval-Augmented Generation)**. Ассистент отвечает строго по загруженной нормативной базе, поддерживает многошаговый контекст диалога и позволяет в один клик открыть первоисточник с подсветкой конкретной статьи или пункта.

---

## ✨ Ключевые возможности

* **Гибридный поиск (Hybrid RAG):** комбинация лексического поиска **BM25** и семантического векторного поиска **FAISS** (`BAAI/bge-m3`) с последующим **реранкингом** и Parent-Child чанкингом для точного извлечения правовых норм.
* **Верификация ответов по первоисточникам:** под каждым ответом отображаются кликабельные ссылки на нормативные акты. При клике открывается боковая панель просмотра документа (`SourceViewer`) с автоматической прокруткой и подсветкой использованного фрагмента.
* **Контекст диалога и переформулирование запросов (Query Rewriting):** модель учитывает историю переписки и переформулирует уточняющие вопросы в самодостаточные поисковые запросы.
* **Управление сессиями:** создание новых диалогов (в том числе по горячей клавише `⌘K` / `Ctrl+K`), автоматическая генерация заголовков по первому вопросу, переключение между чатами и их удаление с сохранением истории в **SQLite**.
* **Безопасность и строгий режим:** защита от prompt-инъекций и строгая привязка генерации к найденному контексту базы знаний.
* **Современный UI:** светлая и тёмная темы оформления, адаптивная вёрстка на React и Tailwind CSS.

## 🛠 Технологический стек

* **Frontend:** React 18, Vite, Tailwind CSS, Lucide Icons, Nginx
* **Backend:** Python 3.12, FastAPI, Uvicorn, Pydantic, SQLite
* **ML / RAG Pipeline:** FAISS, Rank-BM25, `BAAI/bge-m3` (Embeddings & Reranker), HTTPX
* **Инфраструктура:** Docker, Docker Compose

## 🚀 Быстрый запуск

### 1. Подготовка окружения
Создайте файл `.env` в корне проекта (или в `backend/.env`) и укажите API-ключ и параметры LLM/эмбеддингов:

```env
API_KEY=your_api_key_here
BASE_URL=https://example.com
MODEL_NAME=your_model_name
```

Поместите архив с нормативной базой (`kb.zip`) в директорию `backend/data/` (или в корень `backend/`).

### 2. Запуск через Docker Compose

```bash
docker compose up --build
```

После завершения сборки и построения поискового индекса приложение будет доступно по адресу:
* **Веб-интерфейс:** `http://localhost`
* **Swagger API документация:** `http://localhost:8000/docs`

## 🔌 Основные API-эндпоинты

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/health` | Проверка статуса сервера, количества документов и чанков в индексе |
| `GET` | `/api/chats` | Получение списка всех диалогов |
| `POST` | `/api/chats` | Создание нового пустого диалога |
| `GET` | `/api/chats/{chat_id}` | Загрузка истории сообщений и источников конкретного диалога |
| `DELETE` | `/api/chats/{chat_id}` | Удаление диалога |
| `POST` | `/api/chat` | Отправка вопроса в RAG-пайплайн и получение ответа со ссылками на источники |
| `GET` | `/api/documents/{doc_id}` | Получение полного структурированного текста нормативного документа |
